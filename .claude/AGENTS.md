# DataRework project guidance

## Workflow reference

Use [docs/datarework-workflow.html](docs/datarework-workflow.html) as the project workflow reference for future tasks. Read its relevant sections before analyzing or changing application workflows, database queries, packaging relationships, serial synchronization, or data extensions.

The report explains function interactions, data contracts, existing limitations, and proposed improvements. Distinguish implemented behavior from proposals; do not assume a documented recommendation has been implemented.

Verify relevant details against the current source code and available schema evidence. If they disagree, use the verified implementation to describe current behavior and update the report accordingly. When a task changes a documented workflow or resolves a documented finding, update the affected report sections so this reference stays current.
