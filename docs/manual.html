Production Rework

DataRework User Manual

How to use every function of DataRework.exe — signing in, searching records, correcting data, managing containers and reporting damage.

Edition: English · Matches the application as of commit 56d0739 · 2026-10-08
Screenshots use sample data, not real production records.

1.What DataRework does

DataRework (the window is titled Production Rework) is the desktop tool used to correct production packaging records after the fact. Every finished product unit is recorded together with the serial numbers of the display box, inner box and carton it was packed into. When a label was scanned wrongly, a unit sits in the wrong box, or a box is damaged, an authorised operator uses DataRework to find the records, correct them, and keep the serial inventory consistent.

How products are packed

Cartoncontains → Innercontains → Displaycontains → Unit

The first three levels are called containers because they hold other things. A unit is the smallest item and holds nothing.

Words used in this manual

TermMeaning
Serial / Serial NoThe unique code printed on a label. Units, displays, inners and cartons each have one.
Roll NoThe label roll a serial was printed from. It follows the serial automatically when a serial is changed.
Record (row)One saved line for one unit, carrying the serials of every container it sits in.
LinkThe saved connection between an item and the container directly above it.
In use / FreeEvery serial in the serial inventory is either in use (attached to something in production) or free. Fixing records moves serials between the two states.
DamagedA free serial that has been flagged as unusable (see Report damage).

2.Before you start

The program files

DataRework is delivered as a folder. Keep these three files together; copy the whole folder when moving to another computer.

FilePurpose
DataRework.exeThe application you open and work in.
SerialStoreSync.exeA background program that keeps the serial usage counts up to date (see below). You never open it yourself.
nssm.exeThe helper that installs the background program as a Windows service.

The background sync service

The first time DataRework opens on a computer, Windows shows a User Account Control (UAC) prompt. It is asking permission to install the DataRework Serial Store Sync service. Choose Yes (an administrator password may be requested).

  • The service starts automatically with Windows and keeps running after you close DataRework.
  • About every 10 seconds it recounts how many serials are in use and damaged for each roll. After you save a change, those totals can lag by about 10 seconds.
  • If you decline the prompt DataRework still works, but the totals will not update until the service is installed. The prompt appears again the next time you start the program.

Who can do what

What you can change depends on the role of your account. Your role is shown next to your name at the top right of the window.

RoleCan doCannot do
admin / super admin
Everything: search, browse, edit cells, delete rows, Save, rename containers, delete containers, report damage. super admin has exactly the same power as admin.—
any other role (for example user)Search, filter, browse containers, view records, Report damage.Edit cells, delete rows, Save, rename or delete containers. These buttons are greyed out and show a tooltip such as “Only admins can save changes”.
Report damage is open to every role

The Report damage tab has no administrator check. Anyone who can sign in can flag a serial as damaged, and the app has no undo for it.

Barcode scanners

Keyboard-style scanners type the code and then press Enter. DataRework is built for this: in the Value box Enter runs the search; in the Rename and Delete dialogs Enter only looks the serial up and never confirms anything; in Report damage Enter submits the report straight away.

Remembered settings

DataRework remembers, per Windows user: the language (EN / TH), the colour theme (Dark / Light), and whether the filter panel is folded on each tab.

3.Signing in

  1. Open DataRework.exe. The sign-in window appears.
  2. Type your Username and Password. Tick Show password to check what you typed.
  3. Press Enter or click Login.
  4. The main window opens and the sign-in window closes.

You can switch the language with the EN / TH buttons at the top right of the sign-in window.

If sign-in fails

MessageWhat it means and what to do
Invalid username or passwordThe password is wrong. The password box is cleared; type it again.
This user does not have permission to Log inYour account has been deactivated. Ask your administrator.
This user does not have permission to reworkYour account is not allowed to use this application. Ask your administrator to enable rework access.
Unable to reach the databaseThe computer cannot reach the company database (network, VPN or server problem). Check the connection and try again; if it persists, contact IT.
Nothing happensIf the username you typed does not exist the window may simply not respond. Re-check the spelling of the username.

5.Filters

The filter panel decides which records are loaded. It sits above the tabs and is shared by the Records and Container manager tabs. It is applied when you click Search (or press Enter in the Value box).

Date: Day, Month, Year

  • Month and Year start on today’s month and year, so you see this month’s records first. The Year list runs from last year to four years ahead.
  • Leave Day on its placeholder to include every day. The day list shortens to the days the chosen month really has (February never offers a 30th).
  • Select the first entry (“Month” / “Year”) to drop that part of the date filter.
“My records are missing” — check the date first

Because Month and Year default to today, records created in other months do not appear until you change them. This is the most common reason a search looks empty. The date is not reset by Clear.

Product name and Ass. job no.

  • Type a value or pick one from the drop-down. A value you type that is not in the list is still used.
  • The lists are cascading: they only offer values that exist for the chosen date, and the product list narrows further once an Ass. job no. is chosen. Each list shows up to 300 values.
  • The match is exact (equal to what you typed).

Category, Tag and Value — find one specific serial

  1. Pick a Category: Unit, Inner, Display or Carton.
  2. Pick a Tag: Serial No, Roll No, Source ID or Target ID (only those that exist for that level are offered). Serial No is chosen for you.
  3. Type or scan the Value, or pick one from the list (typing narrows the list).
  4. Press Enter in the Value box, or click Search.
Exact match

The value must match exactly, ignoring upper/lower case: searching for 1 finds 1 but not 10 or 201. You may use % (any characters) and _ (one character) as wildcards.

If the filter is incomplete the search still runs, and the status line warns you, for example category/tag filter skipped (no value entered).

Search, Clear and folding the panel

ControlEffect
SearchLoads the Records grid using the filters. It also leaves any single-container view (see “Showing the records in …”).
ClearEmpties Ass. job no., Product name, Category, Tag and Value and returns the Container manager to “All cartons”. It does not reset the date and does not reload or empty the grid — rows already shown stay until you search again.
Hide filters / Show filtersFolds the panel to one line that still summarises what is filtered (for example “Filtering by October 2026 · AJ-26-0042”). The Records tab starts unfolded; the Container manager tab starts folded. Each tab remembers your choice.

6.The Records tab

Loading records

Set your filters and click Search. The status line reports 24 row(s) loaded.

The grid shows at most 500 rows

Rows come back in no particular order and the list stops at 500. If you see exactly 500, there are probably more: narrow the filters (day, job, a specific serial). Sorting a column only re-orders the rows already loaded; it does not fetch the “first” or “last” ones.

Reading the grid

  • Each row is one unit. The columns begin with the record id, the job, product and creation time, followed by four columns for each level: Serial No, Roll No, Source ID and Target ID.
  • Hide columns you do not need by unticking them in the Columns strip (scroll it sideways if it is long). Hiding only changes what you see.
  • Sort by clicking a column header: ▲ ascending, click again ▼ descending. Numbers sort as numbers. The delete-tick column cannot be sorted.
  • Drag the edge of a header to change a column’s width. Click, drag, or Shift/Ctrl-click to select rows.

Editing cells (admins)

  1. Double-click a cell (or select it and press F2), type the new value, press Enter.
  2. The cell turns green: it is changed on screen but not yet saved. Typing the original value back removes the green.
  3. Edit as many cells as you need, then click Save (see below).

Cells you cannot edit

The display, inner and carton Serial No and Roll No cells are read-only: one container label is shared by many rows, so changing it in one row would silently change it for the others. Hover over such a cell to read the explanation. To change a container serial, right-click the cell and choose Rename this … (see “Renaming a container”). Unit cells are editable because a unit belongs to exactly one row.

What changing a unit serial also does
  • The roll number that belongs to the new serial is looked up in the serial inventory and filled in for you (unless you typed a roll number yourself in the same save).
  • The old serial is freed (no longer in use) and the new serial is marked in use.
  • The new serial must exist in the serial inventory. If it does not, the save is refused and nothing is changed.

Deleting records (admins)

  1. Tick the Del box at the start of each row you want to remove — or select rows (click, drag, Shift/Ctrl) and click Delete in the footer, which ticks them all.
  2. The rows turn red. Nothing is deleted yet. Untick the box to undo.
  3. Click Save and confirm.

When rows are deleted their unit serials are freed, their links are removed, and any display or inner box that is left with nothing inside is removed too (its serial is freed as well). Other rows in the same box are never touched. To remove a whole box and everything in it, use Delete container instead.

Saving

  1. Click Save. If there is nothing to save the status line says No changes to save.
  2. A confirmation asks, for example: “This will update 1 row(s) and delete 1 row(s) in public.filling_product_logs. This cannot be undone. Continue?” The default answer is No.
  3. Click Yes. The status line reports Changes saved. and the grid reloads with your changes.

Saving is all or nothing: every edit and deletion is written in one step, and if any part fails (for example a serial that is already in use) nothing is written at all. The error appears in red in the status line.

Cancel does not mean “undo”

Cancel throws everything away

The footer Cancel button clears all the filters and empties the grid, discarding every unsaved edit and deletion mark — without asking. The status line says “Cleared.”. To undo a single edit, retype the original value; to undo a deletion mark, untick the box. To simply reload, use Search.

Right-click menu

Right-click a display, inner or carton Serial No cell (admins) to get Rename this display… / Delete this display… (the word follows the column). The dialog opens with that serial already filled in.

Rename, Delete container, and opening a container’s records are refused while you have unsaved edits, because they reload the grid. Save or cancel first.

Showing one container’s records

When you click View records on a container card, the grid shows only that container’s rows and a bar appears above it, such as “Showing the records in ▢ C260800001 › ▢ I26080011 › ▢ D260800111”. Click Show all records to return to whatever the filter panel says. Your filters are never changed by this.

7.The Container manager tab

This tab lets you browse the packing structure like folders: cartons contain inner boxes, inner boxes contain displays, displays contain units. Counts follow the active filters and include all matching saved rows (not limited to 500).

Cards

Each card is one container. The coloured top edge and icon show its level: carton amber, inner violet, display blue, unit green. A card shows the serial, how many items are inside, and how many saved rows it covers.

ButtonWhat it does
Open boxGoes inside this container and shows its children as cards.
View recordsSwitches to the Records tab showing only this container’s rows. (On a unit card this is the main button.)
RenameOpens the Rename dialog for this serial (admins).
DeleteOpens the Delete container dialog for this serial (admins). Unit cards have no Delete — units are deleted in the Records grid.

A card named Unassigned groups rows that have no container at that level. It has no serial, so it cannot be renamed or deleted.

If a product picture has been set up, cards can show it as a small thumbnail (unit cards by default; box cards when an image is configured for that level); click it to enlarge. (Pictures are added by IT — see docs/product-avatars.md.)

Moving around

  • The trail at the top (“All cartons › carton › inner …”) shows where you are. Click any part of it to jump back there.
  • ← and → are Back and Forward through the places you visited (keyboard: Alt+← / Alt+→). Hover to see where they lead. The page you were on at each level is remembered.
  • The box Find serial in this level filters the cards on the current level by part of a serial.
  • At the bottom, ← Previous / Next → turn pages (as many cards fit as your window allows, up to 20 per page).
  • Refresh reloads the cards — use it after someone else has changed data.
  • A strip such as “Filtering by AJ-26-0042” with Show all explains why some containers are missing; Show all clears job, product, category, tag and value (the date stays).

8.Renaming a container

Use this when a carton, inner or display label carries the wrong serial, or when you need to change a unit serial by scanning it. A rename is applied immediately; it does not wait for Save. Admins only.

Start it from the footer button Rename container…, the Rename link on a card, or by right-clicking a serial cell in the grid.

Stage 1: rename the container

  1. Choose the Level: Carton, Inner, Display or Unit.
  2. In the first box scan or type the current serial (or pick it from the list). Press Enter to jump to the second box. The line under the boxes tells you how much will change, e.g. “12 row(s) and 15 link(s) name “I26080011”. All of them will be rewritten.”
  3. In the second box scan or type the new serial. It starts filled with the old serial so you can edit just a few characters. A scanner’s Enter never submits the dialog.
  4. Click Rename (enabled once the new serial differs from the old).
  5. Read the confirmation (it states the number of rows and links) and click Yes.

The status line then reads, for example Renamed inner "I26080011" to "I26089011" — 12 row(s), 15 link(s).

The rename rewrites every row and link that names the serial, carries the roll number along, frees the old serial and marks the new one in use. It is refused (and nothing changes) if the new serial is already used somewhere, if the old one does not exist, or if the new serial is not in the serial inventory.

Stage 2: rename the children (after a carton, inner or display)

If the renamed carton, inner or display holds anything (inner boxes, displays or units), a second window, Rename children, lists what it holds. It is a separate step after the parent rename has already been saved.

  • Each row shows the old serial, a suggested new serial and how many items are inside. The suggestion replaces the old parent code found inside the child’s serial with the new one; if the child’s serial does not contain it, the suggestion is unchanged and nothing will be renamed until you type a new value.
  • Tick the rows to rename (use Select all / Select none), and edit any new serial by hand.
  • The button reads Apply or “Apply N change(s)”. It stays disabled while two children would get the same serial (a warning says which).
  • Skip closes the window and leaves the children as they are. The parent rename stays in place either way.
There is no Undo

To reverse a rename you must rename it back, which is a new rename subject to the same checks. Check the serials and counts in the confirmation before you click Yes.

9.Deleting a container

Deleting a container removes the box and everything inside it: its saved rows, its links and everything below it. Admins only; it happens immediately, not at Save. Start it from Delete container…, the Delete link on a card, or by right-clicking a serial cell.

  1. Choose the Level: Carton, Inner or Display (units are deleted in the Records grid).
  2. Scan, type or pick the serial. No container is pre-selected and the Delete button stays disabled until a container has been found.
  3. Read the list under Inside this container (nested items are indented) and the summary, e.g. “12 unit(s) · 12 saved row(s) · 15 link(s) will be deleted.” If a parent box would be left empty by this, a line says it will be removed too.
  4. Click Delete. Enter never confirms. A final question states the exact numbers; answer Yes to proceed.

On success Deleted inner "I26080011" — 12 row(s), 15 link(s), 12 unit serial(s) released. The serials of the container and everything under it are freed so they can be used again.

Safeguards

  • If the contents changed between the moment you looked and the moment you confirmed (someone else is working on it), the delete is refused and nothing is deleted.
  • It refuses when the serial names more than one container, or when a container sits under more than one parent, rather than guessing.
  • Pending grid edits must be saved or cancelled first.
This cannot be undone

A deleted container, its rows and its links are gone. Always read the “Inside this container” list first.

10.Report damage

Use this tab to flag a serial as damaged — for example a label that is destroyed and can never be scanned again. It works for a serial at any level: unit, display, inner or carton.

  1. Open the Report damage tab. The cursor is already in the box.
  2. Scan or type the damaged serial and press Enter (or click Report damage).
  3. On success the status below the box reads Reported "U2608012345" damaged. and the box is cleared, ready for the next scan.

Only a serial that is not in use can be reported

If the serial is still attached to a unit or container in production, a window Serial in use asks whether to open it in the records editor.

  1. Click Yes. DataRework switches to the Records tab, filtered to that serial.
  2. Take the serial out of use: delete the unit’s row, or delete the container, or rename the container onto a different serial (this frees the old one).
  3. Return to the Report damage tab and report the serial again.
  • If the serial is not in the serial inventory at all, you see No serial "X" found in staging_serial_data. Check for a typing mistake.
  • The damaged total for the roll updates within about 10 seconds (background service).
Immediate, with no confirmation and no undo

Pressing Enter reports the serial at once. The app does not record who reported it or when, and offers no way to clear the flag. Double-check what you scanned. This tab does not delete or alter any records; it only flags the serial in the inventory.

11.Status line and error log

The line at the bottom left is the status line. Green means the last action worked; red means it did not. It shows one short sentence. Search warnings (for example a filter that was skipped) are appended after the row count.

The error log

Click Log to open the Error log window. It lists the most recent errors with the time, the message and the technical detail, newest last. It stays open while you keep working.

  • Copy copies the whole log to the clipboard — paste it into your message when you ask IT for help.
  • Clear empties the log; Close closes the window.
  • The log holds the last 500 entries in memory only. It is never saved to disk and is lost when you close DataRework, so copy it before you quit.

12.Step-by-step recipes

A. Find one unit by scanning it

  1. Set Month/Year to when it was made (or leave today’s), set Category = Unit, Tag = Serial No.
  2. Click into Value, scan the label. The scanner’s Enter runs the search.
  3. One row appears. Scroll right (or tick columns in the strip) to see its display, inner and carton.

B. Correct a wrongly scanned unit serial

  1. Find the row (recipe A).
  2. Double-click its Unit Serial No cell and type the correct serial. The cell turns green.
  3. Click Save → Yes. If the correct serial is not in the inventory, the save is refused with a message that nothing was changed.

C. Take a unit out of its box

  1. Find the row, tick its Del box, click Save → Yes.
  2. The unit’s serial is freed. If that was the last unit in a display, the empty display is removed too.

D. Fix a wrong carton, inner or display label

  1. Click Rename container… (or right-click the serial in the grid).
  2. Pick the level, scan the current serial, scan the new one, Rename, Yes.
  3. In the Rename children window tick the children that should follow, Apply — or Skip.

E. Remove an entire box

  1. Click Delete container…, pick the level, scan the serial.
  2. Read what is listed inside. Click Delete, then Yes.

F. Report a damaged label

  1. Open Report damage, scan the serial, Enter.
  2. If told it is still in use, answer Yes, free it (recipe C or E, or rename), then report again.

G. See what is inside a carton

  1. Open Container manager, find the carton card (use the search box if needed), click Open box.
  2. Keep clicking Open box to go down to displays and units, or View records to see the rows in the grid.
