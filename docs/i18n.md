# English / Thai translations

Use the EN / TH buttons on the login or main screen to switch languages.
The selection is saved with the theme in the application's QSettings.
Changing languages updates the existing widgets without reloading database
records, changing filters, or discarding pending edits.

`locales/en.json` and `locales/th.json` are UTF-8 i18n catalogs. English source
messages are the keys; interpolated values use named `{p0}`, `{p1}` placeholders.
Keep the keys and placeholders identical in both catalogs. PyInstaller bundles
both files via `DataRework.spec`.

Mark presentation strings with `tr("English message")`, or
`tr("Inside {p0} {p1}", p0=tr(level), p1=serial)`. Widgets imported from
`i18n_widgets` retain these messages and update them when the language changes.
Use ordinary strings for user input, serial numbers, product values, and SQL
identifiers. Translate only the display label with `column_label(column)`;
keep the original column as the data key. Add deployment-specific columns to
both catalogs; unknown columns fall back to their original identifier.
Raw database/driver diagnostics remain unchanged.

## Shared typography

`typography.py` selects an installed family with both English and Thai glyphs:
Leelawadee UI, Noto Sans Thai, Tahoma, Thonburi, then Leelawadee. It also checks
other installed Thai families before falling back to Qt's system font. The
selection stays the same when switching languages. No font downloads or
network access are required. Devices without Thai font coverage still need an
appropriate font installed; UTF-8 encoding alone cannot provide missing glyphs.

The shared scale uses 14px body text, 13px secondary text, 12px captions, 20px
dialog titles and 24px page titles. `theme.py` injects the family and sizes into
both stylesheets. These are Qt logical pixels, which scale with display DPI.
Symbol fallback families handle arrows without changing the English/Thai face.
Keep Thai text at natural letter spacing, including serial fields and logs.

Localized action buttons reserve the widest EN/TH label. Table rows, filter
controls, the column strip and container cards leave space for combining marks;
container pagination uses the taller card size and retains a full visible row.
Keep catalogs and stylesheets saved as UTF-8 and never encode database values
through a legacy code page to solve a display issue.

`tests/test_typography.py` checks glyph coverage, button size stability, pending
edits during language switching and Thai login control height. On Windows,
these offscreen tests register existing OS fonts in the test process only.
Font metric checks are skipped when no Thai font is installed.

Run the isolated UI checks without a database:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -p test_i18n.py -v
```
