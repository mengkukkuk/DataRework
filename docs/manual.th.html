1.DataRework ใช้ทำอะไร

DataRework (หน้าต่างโปรแกรมใช้ชื่อ Production Rework) คือโปรแกรมเดสก์ท็อปสำหรับแก้ไขข้อมูลการบรรจุสินค้าในสายการผลิตย้อนหลัง สินค้าแต่ละหน่วยจะถูกบันทึกพร้อมรหัสซีเรียลของกล่องแสดงสินค้า กล่องชั้นใน และลังที่บรรจุอยู่ เมื่อสแกนฉลากผิด หน่วยสินค้าอยู่ผิดกล่อง หรือกล่องเสียหาย ผู้ที่ได้รับอนุญาตสามารถใช้ DataRework ค้นหา แก้ไขข้อมูล และดูแลให้คลังรหัสซีเรียลถูกต้องตรงกัน

โครงสร้างการบรรจุ

ลังบรรจุ → กล่องชั้นในบรรจุ → กล่องแสดงสินค้าบรรจุ → หน่วยสินค้า

สามระดับแรกเรียกว่าบรรจุภัณฑ์ เพราะบรรจุสิ่งอื่นไว้ภายใน ส่วนหน่วยสินค้าเป็นรายการที่เล็กที่สุดและไม่ได้บรรจุสิ่งใดต่อ

คำศัพท์ที่ใช้ในคู่มือนี้

คำศัพท์ความหมาย
รหัสซีเรียลรหัสเฉพาะที่พิมพ์บนฉลาก หน่วยสินค้า กล่องแสดงสินค้า กล่องชั้นใน และลัง ต่างมีรหัสของตัวเอง
หมายเลขม้วนม้วนฉลากที่ใช้พิมพ์รหัสซีเรียลนั้น ระบบจะเปลี่ยนตามรหัสซีเรียลให้อัตโนมัติเมื่อมีการเปลี่ยนรหัส
ข้อมูล (แถว)ข้อมูลหนึ่งบรรทัดของหน่วยสินค้าหนึ่งหน่วย พร้อมรหัสของบรรจุภัณฑ์ทุกระดับที่หน่วยนั้นอยู่
การเชื่อมโยงความสัมพันธ์ที่บันทึกไว้ระหว่างรายการหนึ่งกับบรรจุภัณฑ์ที่อยู่เหนือขึ้นไปหนึ่งระดับ
ใช้งานอยู่ / ว่างรหัสซีเรียลทุกตัวในคลังรหัสจะอยู่ในสถานะใช้งานอยู่ (ผูกกับสินค้าในสายการผลิต) หรือว่าง การแก้ไขข้อมูลจะย้ายรหัสระหว่างสองสถานะนี้
เสียหายรหัสซีเรียลที่ว่างและถูกทำเครื่องหมายว่าใช้งานไม่ได้ (ดูหัวข้อ Report damage)

2.ก่อนเริ่มใช้งาน

ไฟล์ของโปรแกรม

DataRework ส่งมอบเป็นโฟลเดอร์ ให้เก็บไฟล์ทั้งสามนี้ไว้ด้วยกัน และคัดลอกทั้งโฟลเดอร์เมื่อย้ายไปเครื่องอื่น

ไฟล์หน้าที่
DataRework.exeโปรแกรมที่คุณเปิดใช้งาน
SerialStoreSync.exeโปรแกรมทำงานเบื้องหลังที่ปรับจำนวนการใช้รหัสซีเรียลให้เป็นปัจจุบัน (ดูด้านล่าง) ไม่ต้องเปิดเอง
nssm.exeตัวช่วยติดตั้งโปรแกรมเบื้องหลังเป็นบริการ (service) ของ Windows

บริการซิงก์เบื้องหลัง

เมื่อเปิด DataRework ครั้งแรกบนเครื่อง Windows จะแสดงหน้าต่าง User Account Control (UAC) เพื่อขออนุญาตติดตั้งบริการ DataRework Serial Store Sync ให้เลือก Yes (อาจต้องใส่รหัสผ่านผู้ดูแลเครื่อง)

  • บริการจะเริ่มทำงานพร้อม Windows และทำงานต่อแม้ปิด DataRework แล้ว
  • ทุกประมาณ 10 วินาที บริการจะนับจำนวนรหัสที่ใช้งานอยู่และเสียหายของแต่ละม้วนใหม่ ดังนั้นหลังบันทึก ยอดรวมอาจล่าช้าได้ประมาณ 10 วินาที
  • หากไม่อนุญาต DataRework ยังใช้งานได้ แต่ยอดรวมจะไม่อัปเดตจนกว่าจะติดตั้งบริการ และจะถามอีกครั้งเมื่อเปิดโปรแกรมครั้งต่อไป

ใครทำอะไรได้บ้าง

สิ่งที่คุณแก้ไขได้ขึ้นกับบทบาท (role) ของบัญชี ซึ่งแสดงอยู่ถัดจากชื่อของคุณที่มุมขวาบนของหน้าต่าง

บทบาททำได้ทำไม่ได้
admin / super admin
ผู้ดูแลระบบ / ผู้ดูแลระบบสูงสุด		ทุกอย่าง: ค้นหา เรียกดู แก้ไขเซลล์ ลบแถว บันทึก เปลี่ยนรหัสบรรจุภัณฑ์ ลบบรรจุภัณฑ์ และ Report damage โดย super admin มีสิทธิ์เท่ากับ admin ทุกประการ—
บทบาทอื่น (เช่น ผู้ใช้)ค้นหา กรองข้อมูล เรียกดูบรรจุภัณฑ์ ดูข้อมูล และ Report damageแก้ไขเซลล์ ลบแถว บันทึก เปลี่ยนรหัสหรือลบบรรจุภัณฑ์ ปุ่มเหล่านี้จะเป็นสีเทาและมีคำอธิบายเมื่อชี้เมาส์ เช่น “เฉพาะผู้ดูแลระบบเท่านั้นที่บันทึกการเปลี่ยนแปลงได้”
Report damage ใช้ได้ทุกบทบาท

แท็บ Report damage ไม่ตรวจสอบสิทธิ์ผู้ดูแลระบบ ทุกคนที่เข้าสู่ระบบได้สามารถทำเครื่องหมายรหัสว่าเสียหายได้ และโปรแกรมไม่มีปุ่มย้อนกลับ

เครื่องสแกนบาร์โค้ด

เครื่องสแกนแบบคีย์บอร์ดจะพิมพ์รหัสแล้วกด Enter ให้เอง DataRework ออกแบบให้รองรับการทำงานนี้: ในช่องค่า Enter จะค้นหาทันที ในหน้าต่างเปลี่ยนรหัสและลบ Enter เพียงค้นหารหัสและไม่ยืนยันการทำรายการใด ๆ ส่วนใน Report damage Enter จะส่งรายงานทันที

การตั้งค่าที่โปรแกรมจำไว้

DataRework จำค่าต่อไปนี้ไว้สำหรับผู้ใช้ Windows แต่ละคน: ภาษา (EN / TH) ธีมสี (มืด / สว่าง) และสถานะการพับตัวกรองในแต่ละแท็บ

3.การเข้าสู่ระบบ

  1. เปิด DataRework.exe หน้าต่างเข้าสู่ระบบจะปรากฏขึ้น
  2. พิมพ์ชื่อผู้ใช้และรหัสผ่าน ติ๊ก แสดงรหัสผ่าน หากต้องการตรวจสอบสิ่งที่พิมพ์
  3. กด Enter หรือคลิก เข้าสู่ระบบ
  4. หน้าต่างหลักจะเปิดขึ้น และหน้าต่างเข้าสู่ระบบจะปิดลง

สามารถสลับภาษาได้ด้วยปุ่ม EN / TH ที่มุมขวาบนของหน้าต่างเข้าสู่ระบบ

หากเข้าสู่ระบบไม่ได้

ข้อความความหมายและสิ่งที่ควรทำ
ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้องรหัสผ่านไม่ถูกต้อง ช่องรหัสผ่านจะถูกล้าง ให้พิมพ์ใหม่อีกครั้ง
User นี้ไม่สามารถ Log in ได้บัญชีของคุณถูกปิดการใช้งาน โปรดติดต่อผู้ดูแลระบบ
User นี้ไม่สามารถใช้งาน rework ได้บัญชีของคุณยังไม่ได้รับสิทธิ์ใช้โปรแกรมนี้ โปรดขอให้ผู้ดูแลระบบเปิดสิทธิ์ rework
ไม่สามารถเชื่อมต่อฐานข้อมูลได้เครื่องของคุณเชื่อมต่อฐานข้อมูลของบริษัทไม่ได้ (ปัญหาเครือข่าย VPN หรือเซิร์ฟเวอร์) ตรวจสอบการเชื่อมต่อแล้วลองใหม่ หากยังไม่ได้ให้ติดต่อฝ่าย IT
ไม่มีอะไรเกิดขึ้นหากชื่อผู้ใช้ที่พิมพ์ไม่มีอยู่ในระบบ หน้าต่างอาจไม่ตอบสนองและไม่แสดงข้อความ ให้ตรวจสอบการสะกดชื่อผู้ใช้อีกครั้ง

5.ตัวกรอง

แผงตัวกรองกำหนดว่าจะโหลดข้อมูลใดบ้าง อยู่เหนือแท็บและใช้ร่วมกันระหว่างแท็บรายการข้อมูลและจัดการบรรจุภัณฑ์ ตัวกรองจะทำงานเมื่อคลิก ค้นหา (หรือกด Enter ในช่องค่า)

วันที่: วันที่ เดือน ปี

  • เดือนและปีจะเริ่มต้นที่เดือนและปีของวันนี้ จึงเห็นข้อมูลของเดือนปัจจุบันก่อน รายการปีเริ่มจากปีที่แล้วไปถึงอีกสี่ปีข้างหน้า
  • เว้นวันที่ไว้ที่ค่าเริ่มต้นเพื่อรวมทุกวัน รายการวันจะปรับตามจำนวนวันจริงของเดือนที่เลือก (กุมภาพันธ์จะไม่มีวันที่ 30)
  • เลือกรายการแรก (“เดือน” / “ปี”) เพื่อยกเลิกเงื่อนไขส่วนนั้นของวันที่
“ข้อมูลหาย” — ให้ตรวจวันที่ก่อน

เพราะเดือนและปีตั้งต้นเป็นวันนี้ ข้อมูลที่สร้างในเดือนอื่นจึงไม่แสดงจนกว่าจะเปลี่ยนค่า นี่คือสาเหตุที่พบบ่อยที่สุดที่ทำให้ผลค้นหาว่าง และปุ่ม ล้าง ไม่ได้รีเซ็ตวันที่

ชื่อผลิตภัณฑ์และเลขที่ใบสั่งงาน

  • พิมพ์ค่าหรือเลือกจากรายการ หากพิมพ์ค่าที่ไม่อยู่ในรายการ ระบบก็ยังใช้ค่านั้นกรอง
  • รายการเป็นแบบเชื่อมโยงกัน: แสดงเฉพาะค่าที่มีอยู่ในวันที่ที่เลือก และรายการชื่อผลิตภัณฑ์จะแคบลงอีกเมื่อเลือกเลขที่ใบสั่งงาน แต่ละรายการแสดงได้สูงสุด 300 ค่า
  • ใช้การจับคู่แบบตรงทุกตัวอักษร (เท่ากับที่พิมพ์)

ระดับบรรจุภัณฑ์ พารามิเตอร์ และค่า — ค้นหารหัสที่ต้องการ

  1. เลือกระดับบรรจุภัณฑ์: หน่วยสินค้า กล่องชั้นใน กล่องแสดงสินค้า หรือ ลัง
  2. เลือกพารามิเตอร์: รหัสซีเรียล หมายเลขม้วน รหัสต้นทาง หรือ รหัสปลายทาง (แสดงเฉพาะที่มีในระดับนั้น) ระบบเลือก รหัสซีเรียล ให้อัตโนมัติ
  3. พิมพ์หรือสแกนค่า หรือเลือกจากรายการ (พิมพ์เพื่อกรองรายการ)
  4. กด Enter ในช่องค่า หรือคลิก ค้นหา
จับคู่แบบตรงทุกตัวอักษร

ค่าต้องตรงกันทุกตัวอักษร โดยไม่สนใจตัวพิมพ์เล็ก/ใหญ่ เช่น ค้นหา 1 จะพบ 1 แต่ไม่พบ 10 หรือ 201 สามารถใช้ % (กี่ตัวอักษรก็ได้) และ _ (หนึ่งตัวอักษร) เป็นตัวแทนได้

หากกรอกตัวกรองไม่ครบ ระบบยังค้นหาให้ และบรรทัดสถานะจะแจ้งเตือน เช่น ข้ามตัวกรองระดับบรรจุภัณฑ์/พารามิเตอร์ (ยังไม่ได้กรอกค่า).

ค้นหา ล้าง และการพับแผงตัวกรอง

ปุ่มผล
ค้นหาโหลดตารางข้อมูลตามตัวกรอง และออกจากมุมมองเฉพาะบรรจุภัณฑ์ (ดู “กำลังแสดงข้อมูลใน …”)
ล้างล้างเลขที่ใบสั่งงาน ชื่อผลิตภัณฑ์ ระดับบรรจุภัณฑ์ พารามิเตอร์ และค่า และพาตัวจัดการบรรจุภัณฑ์กลับไปที่ “ลังทั้งหมด” แต่ไม่รีเซ็ตวันที่ และไม่โหลดหรือเคลียร์ตารางใหม่ แถวที่แสดงอยู่จะยังอยู่จนกว่าจะค้นหาอีกครั้ง
ซ่อนตัวกรอง / แสดงตัวกรองพับแผงเหลือบรรทัดเดียวที่ยังสรุปตัวกรองไว้ (เช่น “กรองด้วย ตุลาคม 2026 · AJ-26-0042”) แท็บรายการข้อมูลเริ่มต้นแบบกางออก แท็บจัดการบรรจุภัณฑ์เริ่มต้นแบบพับ และแต่ละแท็บจำค่าที่คุณเลือก

6.แท็บรายการข้อมูล

การโหลดข้อมูล

ตั้งตัวกรองแล้วคลิก ค้นหา บรรทัดสถานะจะแสดง โหลดแล้ว 24 แถว

ตารางแสดงได้สูงสุด 500 แถว

ข้อมูลจะไม่เรียงลำดับตายตัวและหยุดที่ 500 แถว หากเห็น 500 แถวพอดี แสดงว่ามีมากกว่านั้น ให้กรองให้แคบลง (วัน ใบสั่งงาน หรือรหัสเฉพาะ) การจัดเรียงคอลัมน์เป็นเพียงการเรียงแถวที่โหลดแล้ว ไม่ได้ดึงแถวแรกหรือแถวสุดท้ายจริง ๆ

การอ่านตาราง

  • แต่ละแถวคือหนึ่งหน่วยสินค้า คอลัมน์เริ่มจากรหัสข้อมูล id เลขที่ใบสั่งงาน ชื่อผลิตภัณฑ์ และเวลาที่สร้าง ตามด้วยสี่คอลัมน์ของแต่ละระดับ ได้แก่ รหัสซีเรียล หมายเลขม้วน รหัสต้นทาง และรหัสปลายทาง
  • ซ่อนคอลัมน์ที่ไม่ต้องการโดยเอาเครื่องหมายถูกออกในแถบ คอลัมน์ (เลื่อนไปด้านข้างหากยาว) การซ่อนมีผลเฉพาะการแสดงผล
  • จัดเรียงโดยคลิกหัวคอลัมน์: ▲ น้อยไปมาก คลิกอีกครั้ง ▼ มากไปน้อย ตัวเลขเรียงตามค่าตัวเลข คอลัมน์ช่องติ๊กลบจัดเรียงไม่ได้
  • ลากขอบหัวคอลัมน์เพื่อปรับความกว้าง คลิก ลาก หรือใช้ Shift/Ctrl+คลิกเพื่อเลือกหลายแถว

การแก้ไขเซลล์ (ผู้ดูแลระบบ)

  1. ดับเบิลคลิกเซลล์ (หรือเลือกแล้วกด F2) พิมพ์ค่าใหม่ แล้วกด Enter
  2. เซลล์จะเปลี่ยนเป็นสีเขียว หมายถึงเปลี่ยนบนหน้าจอแล้วแต่ยังไม่ได้บันทึก พิมพ์ค่าเดิมกลับเข้าไปเพื่อเอาสีเขียวออก
  3. แก้ไขได้หลายเซลล์ แล้วคลิก บันทึก (ดูด้านล่าง)

เซลล์ที่แก้ไขไม่ได้

เซลล์ รหัสซีเรียล และ หมายเลขม้วน ของกล่องแสดงสินค้า กล่องชั้นใน และลัง เป็นแบบอ่านอย่างเดียว เพราะรหัสบรรจุภัณฑ์หนึ่งใช้ร่วมกันหลายแถว การแก้ในแถวเดียวจะกระทบแถวอื่นโดยไม่รู้ตัว ชี้เมาส์ที่เซลล์เพื่ออ่านคำอธิบาย หากต้องการเปลี่ยนรหัสบรรจุภัณฑ์ ให้คลิกขวาที่เซลล์แล้วเลือก เปลี่ยนรหัส … นี้ (ดูหัวข้อ “การเปลี่ยนรหัสบรรจุภัณฑ์”) เซลล์ของหน่วยสินค้าแก้ไขได้ เพราะหน่วยสินค้าหนึ่งอยู่ในแถวเดียวเท่านั้น

การเปลี่ยนรหัสซีเรียลของหน่วยสินค้ายังทำอะไรเพิ่มอีก
  • ระบบค้นหมายเลขม้วนของรหัสใหม่จากคลังรหัสและกรอกให้ (เว้นแต่คุณพิมพ์หมายเลขม้วนเองในการบันทึกครั้งเดียวกัน)
  • รหัสเดิมจะถูกปล่อยว่าง (ไม่ได้ใช้งาน) และรหัสใหม่จะถูกทำเครื่องหมายว่าใช้งานอยู่
  • รหัสใหม่ต้องมีอยู่ในคลังรหัส หากไม่มี ระบบจะปฏิเสธการบันทึกและไม่เปลี่ยนแปลงสิ่งใด

การลบข้อมูล (ผู้ดูแลระบบ)

  1. ติ๊กช่อง ลบ ที่ต้นแถวที่ต้องการลบ — หรือเลือกแถว (คลิก ลาก Shift/Ctrl) แล้วคลิก ลบ ที่ท้ายหน้าต่าง ระบบจะติ๊กให้ทั้งหมด
  2. แถวจะเปลี่ยนเป็นสีแดง ยังไม่มีการลบจริง เอาเครื่องหมายถูกออกเพื่อย้อนกลับ
  3. คลิก บันทึก แล้วยืนยัน

เมื่อลบแถว รหัสซีเรียลของหน่วยสินค้าจะถูกปล่อยว่าง การเชื่อมโยงถูกลบ และกล่องแสดงสินค้าหรือกล่องชั้นในที่ไม่เหลือสิ่งใดอยู่ภายในจะถูกลบด้วย (รหัสของกล่องก็ถูกปล่อยว่างเช่นกัน) แถวอื่นในกล่องเดียวกันจะไม่ถูกแตะต้อง หากต้องการลบทั้งกล่องพร้อมทุกอย่างภายใน ให้ใช้ ลบบรรจุภัณฑ์

การบันทึก

  1. คลิก บันทึก หากไม่มีอะไรให้บันทึก บรรทัดสถานะจะแจ้ง ไม่มีการเปลี่ยนแปลงที่จะบันทึก
  2. หน้าต่างยืนยันจะถาม เช่น “การดำเนินการนี้จะอัปเดต 1 แถว และลบ 1 แถว ใน public.filling_product_logs และไม่สามารถย้อนกลับได้ ต้องการดำเนินการต่อหรือไม่?” ค่าเริ่มต้นคือ ไม่
  3. คลิก ใช่ บรรทัดสถานะจะแจ้ง บันทึกการเปลี่ยนแปลงแล้ว และตารางจะโหลดใหม่พร้อมการเปลี่ยนแปลงของคุณ

การบันทึกเป็นแบบทั้งหมดหรือไม่เลย: ทุกการแก้ไขและการลบถูกเขียนในขั้นตอนเดียว หากส่วนใดล้มเหลว (เช่น รหัสที่ถูกใช้งานแล้ว) จะไม่มีอะไรถูกเขียนเลย ข้อผิดพลาดจะแสดงเป็นสีแดงในบรรทัดสถานะ

ยกเลิกไม่ได้หมายถึง “ย้อนกลับ”

ปุ่มยกเลิกทิ้งทุกอย่าง

ปุ่ม ยกเลิก ที่ท้ายหน้าต่างจะล้างตัวกรองทั้งหมดและเคลียร์ตาราง ทิ้งการแก้ไขและเครื่องหมายลบที่ยังไม่บันทึกทั้งหมดโดยไม่ถามยืนยัน บรรทัดสถานะจะแจ้ง “ล้างข้อมูลแล้ว” หากต้องการย้อนเพียงหนึ่งการแก้ไข ให้พิมพ์ค่าเดิมกลับ หากต้องการยกเลิกเครื่องหมายลบ ให้เอาเครื่องหมายถูกออก หรือหากต้องการโหลดใหม่ให้ใช้ ค้นหา

เมนูคลิกขวา

คลิกขวาที่เซลล์ รหัสซีเรียล ของกล่องแสดงสินค้า กล่องชั้นใน หรือลัง (ผู้ดูแลระบบ) จะได้เมนู เปลี่ยนรหัสกล่องแสดงสินค้านี้… / ลบกล่องแสดงสินค้านี้… (คำเปลี่ยนตามคอลัมน์) หน้าต่างจะเปิดพร้อมรหัสนั้นที่กรอกไว้ให้แล้ว

การเปลี่ยนรหัส การลบบรรจุภัณฑ์ และการเปิดข้อมูลของบรรจุภัณฑ์ จะถูกปฏิเสธเมื่อมีการแก้ไขที่ยังไม่บันทึก เพราะต้องโหลดตารางใหม่ ให้บันทึกหรือยกเลิกก่อน

การแสดงข้อมูลเฉพาะบรรจุภัณฑ์

เมื่อคลิก ดูข้อมูล ที่การ์ดบรรจุภัณฑ์ ตารางจะแสดงเฉพาะแถวของบรรจุภัณฑ์นั้น และมีแถบปรากฏด้านบน เช่น “กำลังแสดงข้อมูลใน ▢ C260800001 › ▢ I26080011 › ▢ D260800111” คลิก แสดงข้อมูลทั้งหมด เพื่อกลับไปตามที่แผงตัวกรองกำหนด ตัวกรองของคุณจะไม่ถูกเปลี่ยนจากการนี้

7.แท็บจัดการบรรจุภัณฑ์

แท็บนี้ให้คุณเรียกดูโครงสร้างการบรรจุเหมือนโฟลเดอร์: ลังบรรจุกล่องชั้นใน กล่องชั้นในบรรจุกล่องแสดงสินค้า และกล่องแสดงสินค้าบรรจุหน่วยสินค้า ตัวเลขเป็นไปตามตัวกรองที่ใช้ และนับทุกแถวที่ตรงเงื่อนไข (ไม่จำกัดที่ 500)

การ์ด

การ์ดแต่ละใบคือบรรจุภัณฑ์หนึ่งรายการ ขอบบนและไอคอนสีบอกระดับ: ลัง สีเหลืองอำพัน กล่องชั้นใน สีม่วง กล่องแสดงสินค้า สีน้ำเงิน หน่วยสินค้า สีเขียว การ์ดแสดงรหัส จำนวนรายการภายใน และจำนวนแถวข้อมูลที่บันทึก

ปุ่มผล
เปิดกล่องเข้าไปภายในบรรจุภัณฑ์นี้และแสดงรายการภายในเป็นการ์ด
ดูข้อมูลสลับไปแท็บรายการข้อมูลและแสดงเฉพาะแถวของบรรจุภัณฑ์นี้ (ในการ์ดหน่วยสินค้านี่คือปุ่มหลัก)
เปลี่ยนรหัสเปิดหน้าต่างเปลี่ยนรหัสของรหัสนี้ (ผู้ดูแลระบบ)
ลบเปิดหน้าต่างลบบรรจุภัณฑ์ของรหัสนี้ (ผู้ดูแลระบบ) การ์ดหน่วยสินค้าไม่มีปุ่มลบ — ลบหน่วยสินค้าได้ที่ตารางรายการข้อมูล

การ์ดชื่อ ยังไม่ระบุ รวมแถวที่ไม่มีบรรจุภัณฑ์ในระดับนั้น ไม่มีรหัสจึงเปลี่ยนรหัสหรือลบไม่ได้

หากมีการตั้งรูปผลิตภัณฑ์ไว้ การ์ดสามารถแสดงรูปย่อได้ (การ์ดหน่วยสินค้าเป็นค่าเริ่มต้น ส่วนการ์ดกล่องจะแสดงเมื่อมีการตั้งรูปสำหรับระดับนั้น) คลิกเพื่อขยาย (ฝ่าย IT เป็นผู้เพิ่มรูป — ดู docs/product-avatars.md)

การเลื่อนดู

  • เส้นทางด้านบน (“ลังทั้งหมด › ลัง › กล่องชั้นใน …”) บอกตำแหน่งปัจจุบัน คลิกส่วนใดก็ได้เพื่อกระโดดกลับไปที่นั่น
  • ← และ → คือย้อนกลับและไปข้างหน้าตามที่ที่เคยเข้าไป (แป้นพิมพ์: Alt+← / Alt+→) ชี้เมาส์เพื่อดูว่าจะไปที่ไหน โปรแกรมจำหน้าที่คุณเปิดค้างไว้ในแต่ละระดับ
  • ช่อง ค้นหารหัสในระดับนี้ กรองการ์ดในระดับปัจจุบันตามส่วนหนึ่งของรหัส
  • ด้านล่าง ← Previous / Next → ใช้เปลี่ยนหน้า (จำนวนการ์ดต่อหน้าขึ้นกับขนาดหน้าต่าง สูงสุด 20)
  • รีเฟรช โหลดการ์ดใหม่ — ใช้หลังมีผู้อื่นแก้ไขข้อมูล
  • แถบ เช่น “กรองด้วย AJ-26-0042” พร้อม แสดงทั้งหมด อธิบายว่าเหตุใดบางบรรจุภัณฑ์ไม่แสดง แสดงทั้งหมด จะล้างใบสั่งงาน ผลิตภัณฑ์ ระดับ พารามิเตอร์ และค่า (วันที่ยังอยู่)

8.การเปลี่ยนรหัสบรรจุภัณฑ์

ใช้เมื่อฉลากของลัง กล่องชั้นใน หรือกล่องแสดงสินค้ามีรหัสผิด หรือเมื่อต้องการเปลี่ยนรหัสหน่วยสินค้าด้วยการสแกน การเปลี่ยนรหัสมีผลทันทีไม่ต้องรอกดบันทึก เฉพาะผู้ดูแลระบบ

เริ่มได้จากปุ่มท้ายหน้าต่าง เปลี่ยนรหัสบรรจุภัณฑ์… ปุ่ม เปลี่ยนรหัส บนการ์ด หรือคลิกขวาที่เซลล์รหัสในตาราง

ขั้นที่ 1: เปลี่ยนรหัสบรรจุภัณฑ์

  1. เลือกระดับ: ลัง กล่องชั้นใน กล่องแสดงสินค้า หรือ หน่วยสินค้า
  2. ในช่องแรกให้สแกนหรือพิมพ์รหัสปัจจุบัน (หรือเลือกจากรายการ) กด Enter เพื่อไปช่องที่สอง บรรทัดใต้ช่องจะบอกว่ามีอะไรเปลี่ยนบ้าง เช่น “มี 12 แถวและ 15 การเชื่อมโยงที่อ้างถึง “I26080011” ทั้งหมดจะถูกอัปเดต”
  3. ในช่องที่สองให้สแกนหรือพิมพ์รหัสใหม่ ช่องนี้เริ่มต้นด้วยรหัสเดิมเพื่อให้แก้เพียงไม่กี่ตัวอักษร Enter จากเครื่องสแกนจะไม่ส่งหน้าต่าง
  4. คลิก เปลี่ยนรหัส (ใช้ได้เมื่อรหัสใหม่ต่างจากรหัสเดิม)
  5. อ่านหน้าต่างยืนยัน (ระบุจำนวนแถวและการเชื่อมโยง) แล้วคลิก ใช่

การเปลี่ยนรหัสจะอัปเดตทุกแถวและการเชื่อมโยงที่อ้างถึงรหัสนั้น เปลี่ยนหมายเลขม้วนตาม ปล่อยรหัสเดิมให้ว่างและทำเครื่องหมายรหัสใหม่ว่าใช้งานอยู่ ระบบจะปฏิเสธ (และไม่เปลี่ยนอะไร) หากรหัสใหม่ถูกใช้ที่อื่นแล้ว รหัสเดิมไม่มีอยู่ หรือรหัสใหม่ไม่อยู่ในคลังรหัส

ขั้นที่ 2: เปลี่ยนรหัสรายการภายใน (หลังเปลี่ยนรหัสลัง กล่องชั้นใน หรือกล่องแสดงสินค้า)

หากลัง กล่องชั้นใน หรือกล่องแสดงสินค้าที่เปลี่ยนรหัสมีสิ่งอื่นอยู่ภายใน (กล่องชั้นใน กล่องแสดงสินค้า หรือหน่วยสินค้า) จะมีหน้าต่างที่สอง เปลี่ยนรหัสรายการภายใน แสดงรายการเหล่านั้น เป็นขั้นตอนแยกที่เกิดหลังบันทึกการเปลี่ยนรหัสของบรรจุภัณฑ์หลักไปแล้ว

  • แต่ละแถวแสดงรหัสเดิม รหัสใหม่ที่เสนอ และจำนวนรายการภายใน ข้อเสนอคือแทนที่รหัสของบรรจุภัณฑ์หลักเดิมที่อยู่ในรหัสของรายการภายในด้วยรหัสใหม่ หากรหัสนั้นไม่มีส่วนดังกล่าว ข้อเสนอจะเหมือนเดิมและจะไม่มีการเปลี่ยนจนกว่าจะพิมพ์ค่าใหม่
  • ติ๊กแถวที่ต้องการเปลี่ยนรหัส (ใช้ เลือกทั้งหมด / ยกเลิกการเลือกทั้งหมด) และแก้รหัสใหม่เองได้
  • ปุ่มแสดง นำไปใช้ หรือ “ใช้การเปลี่ยนแปลง N รายการ” จะใช้ไม่ได้ขณะที่รายการภายในสองรายการจะได้รหัสซ้ำกัน (มีคำเตือนบอกรหัสที่ซ้ำ)
  • ข้าม ปิดหน้าต่างและคงรายการภายในไว้ตามเดิม การเปลี่ยนรหัสของบรรจุภัณฑ์หลักยังคงอยู่ไม่ว่าเลือกแบบใด
ไม่มีปุ่มย้อนกลับ

9.การลบบรรจุภัณฑ์

การลบบรรจุภัณฑ์จะลบกล่องพร้อมทุกอย่างที่อยู่ภายใน ได้แก่ แถวข้อมูล การเชื่อมโยง และรายการทั้งหมดที่อยู่ลึกลงไป เฉพาะผู้ดูแลระบบ และมีผลทันทีไม่ต้องรอกดบันทึก เริ่มได้จาก ลบบรรจุภัณฑ์…, ลิงก์ ลบ บนการ์ด หรือคลิกขวาที่เซลล์รหัส

  1. เลือกระดับ: ลัง กล่องชั้นใน หรือ กล่องแสดงสินค้า (ลบหน่วยสินค้าได้ที่ตารางรายการข้อมูล)
  2. สแกน พิมพ์ หรือเลือกรหัส ระบบไม่เลือกบรรจุภัณฑ์ไว้ล่วงหน้า และปุ่มลบจะใช้ไม่ได้จนกว่าจะพบบรรจุภัณฑ์
  3. อ่านรายการใต้ ภายในบรรจุภัณฑ์นี้ (รายการซ้อนจะเยื้องเข้าไป) และสรุป เช่น “จะลบหน่วยสินค้า 12 รายการ · ข้อมูลที่บันทึก 12 แถว · 15 การเชื่อมโยง” หากกล่องแม่จะว่างเปล่าเพราะการลบนี้ จะมีบรรทัดแจ้งว่าจะถูกลบด้วย
  4. คลิก ลบ Enter ไม่เคยเป็นการยืนยัน คำถามสุดท้ายจะระบุจำนวนที่แน่นอน ตอบ ใช่ เพื่อดำเนินการ

เมื่อสำเร็จ ลบกล่องชั้นใน "I26080011" แล้ว — 12 แถว, 15 การเชื่อมโยง, คืนรหัสซีเรียลของหน่วยสินค้า 12 รายการ รหัสซีเรียลของบรรจุภัณฑ์และรายการทั้งหมดภายในจะถูกปล่อยว่างเพื่อใช้ใหม่ได้

การป้องกันความผิดพลาด

  • หากเนื้อหาเปลี่ยนไประหว่างที่คุณดูกับตอนยืนยัน (มีผู้อื่นกำลังแก้ไข) ระบบจะปฏิเสธการลบและไม่ลบอะไรเลย
  • ระบบปฏิเสธเมื่อรหัสตรงกับบรรจุภัณฑ์มากกว่าหนึ่งรายการ หรือเมื่อบรรจุภัณฑ์อยู่ใต้กล่องแม่มากกว่าหนึ่งใบ แทนที่จะเดา
  • ต้องบันทึกหรือยกเลิกการแก้ไขที่ค้างอยู่ในตารางก่อน
ไม่สามารถย้อนกลับได้

บรรจุภัณฑ์ที่ลบ แถวข้อมูล และการเชื่อมโยงจะหายไปถาวร โปรดอ่านรายการ “ภายในบรรจุภัณฑ์นี้” ทุกครั้งก่อนลบ

บันทึกข้อผิดพลาด

คลิก ล็อก เพื่อเปิดหน้าต่างบันทึกข้อผิดพลาด แสดงข้อผิดพลาดล่าสุดพร้อมเวลา ข้อความ และรายละเอียดทางเทคนิค โดยรายการใหม่สุดอยู่ท้าย หน้าต่างนี้เปิดค้างไว้ได้ขณะทำงานต่อ

  • คัดลอก คัดลอกบันทึกทั้งหมดไปยังคลิปบอร์ด — วางในข้อความเมื่อขอความช่วยเหลือจาก IT
  • ล้าง ล้างบันทึก; ปิด ปิดหน้าต่าง
  • บันทึกเก็บ 500 รายการล่าสุดในหน่วยความจำเท่านั้น ไม่เคยบันทึกลงดิสก์ และจะหายเมื่อปิด DataRework ดังนั้นให้คัดลอกก่อนปิดโปรแกรม

12.ขั้นตอนสำหรับงานที่ทำบ่อย

ก. ค้นหาหน่วยสินค้าด้วยการสแกน

  1. ตั้งเดือน/ปีให้ตรงกับวันที่ผลิต (หรือใช้ของวันนี้) ตั้ง ระดับบรรจุภัณฑ์ = หน่วยสินค้า และ พารามิเตอร์ = รหัสซีเรียล
  2. คลิกที่ช่อง ค่า แล้วสแกนฉลาก Enter จากเครื่องสแกนจะค้นหาให้ทันที
  3. จะแสดงหนึ่งแถว เลื่อนไปทางขวา (หรือเลือกคอลัมน์ในแถบ) เพื่อดูกล่องแสดงสินค้า กล่องชั้นใน และลังของมัน

ข. แก้รหัสหน่วยสินค้าที่สแกนผิด

  1. ค้นหาแถว (สูตร ก)
  2. ดับเบิลคลิกเซลล์รหัสซีเรียล (หน่วยสินค้า) แล้วพิมพ์รหัสที่ถูกต้อง เซลล์จะเป็นสีเขียว
  3. คลิก บันทึก → ใช่ หากรหัสที่ถูกต้องไม่มีในคลังรหัส ระบบจะปฏิเสธและแจ้งว่าไม่มีการเปลี่ยนแปลง

ค. นำหน่วยสินค้าออกจากกล่อง

  1. ค้นหาแถว ติ๊กช่อง ลบ ของแถวนั้น คลิกบันทึก → ใช่
  2. รหัสของหน่วยสินค้าจะถูกปล่อยว่าง หากเป็นหน่วยสุดท้ายในกล่องแสดงสินค้า กล่องที่ว่างเปล่านั้นจะถูกลบด้วย

ง. แก้ฉลากลัง กล่องชั้นใน หรือกล่องแสดงสินค้าที่ผิด

  1. คลิก เปลี่ยนรหัสบรรจุภัณฑ์… (หรือคลิกขวาที่รหัสในตาราง)
  2. เลือกระดับ สแกนรหัสปัจจุบัน สแกนรหัสใหม่ เปลี่ยนรหัส ใช่
  3. ในหน้าต่างเปลี่ยนรหัสรายการภายใน ติ๊กรายการที่ต้องเปลี่ยนตาม นำไปใช้ — หรือ ข้าม

จ. ลบกล่องทั้งใบ

  1. คลิก ลบบรรจุภัณฑ์… เลือกระดับ สแกนรหัส
  2. อ่านรายการภายใน คลิกลบ แล้วตอบ ใช่

ฉ. แจ้งฉลากที่เสียหาย

  1. เปิดแท็บ Report damage สแกนรหัส กด Enter
  2. หากแจ้งว่ายังใช้งานอยู่ ให้ตอบใช่ ปล่อยรหัสให้ว่าง (สูตร ค หรือ จ หรือเปลี่ยนรหัส) แล้วรายงานอีกครั้ง

ช. ดูว่าในลังมีอะไรบ้าง

  1. เปิดแท็บ จัดการบรรจุภัณฑ์ หาการ์ดลัง (ใช้ช่องค้นหาได้) แล้วคลิก เปิดกล่อง
  2. คลิก เปิดกล่อง ต่อเพื่อลงไปถึงกล่องแสดงสินค้าและหน่วยสินค้า หรือ ดูข้อมูล เพื่อดูแถวในตาราง
